Build a Personal Design System in a Weekend: Palette, Type Scale, Spacing, 5 Components and a README

You don't need a team to have a design system. Here is a two-day plan to build a small, practical system for your own portfolio, posts and documents, using my GitHub profile system as the case study.

After reading this, you’ll have a two-day plan to build a small personal design system that makes everything you publish look like it belongs together.

Photo by Firmbee on Pixabay (Pixabay Content License).

Why it matters

Most designers spend their time building systems for clients and almost none on their own work. The result: a portfolio, a LinkedIn banner, a CV and a GitHub profile that each look like a different person made them.

A personal design system fixes that. It doesn’t need to be big. In Building a personal design system from one colour I explained the thinking behind my own palette. This post is the practical version: a weekend plan you can follow.

The idea explained

A personal system has five parts. Each one is small:

  1. Palette: one main colour, one accent, neutrals, and light/dark variants.
  2. Type scale: one or two typefaces and five or six sizes.
  3. Spacing scale: a short list of spacing values (for example 4, 8, 12, 16, 24, 32, 48, 64).
  4. Five core components: the things you make most often.
  5. README: one page explaining how to use it.

A real example

My own system started from a single violet and a sharp lime accent, with a deep ink colour for text. I use it across my site, GitHub profile, blog covers and documents.

Before, my GitHub profile README was a list of badges in every colour, mixed fonts in images and no clear structure. After applying the system, it uses the same palette, the same heading style and a consistent card layout as the website.

Try it yourself: the weekend plan

Saturday morning: palette (2 hours) - Pick one main colour that feels like you. - Add one accent with strong contrast. - Add an ink (near-black) and two or three neutrals. - Check text contrast with a WCAG checker.

Saturday afternoon: type and spacing (3 hours) - Choose a display typeface and a text typeface (or one family for both). - Build a scale with a ratio such as 1.25: for example 14, 16, 20, 25, 31, 39 px. - Choose spacing steps based on 4 or 8 px.

Sunday morning: five components (3 hours) Pick the five things you make most. Mine are: 1. Button / link style 2. Card (project or post) 3. Section heading with a small label 4. Social post template 5. Cover/banner template

Build each in Figma using only your palette, type and spacing.

Sunday afternoon: README and rollout (2 hours) - Write one page: colours with values, type sizes, spacing, components, do’s and don’ts. - Apply it to one real thing immediately: your GitHub README, LinkedIn banner or CV.

Common mistakes

  • Too many colours. Start with fewer; you can add later.
  • Building components you never use. Five real ones beat twenty theoretical ones.
  • Skipping the README. Without it, you’ll forget your own rules in a month.
  • Not applying it. A system lives only when it’s used.
  • Changing it every week. Give it three months before redesigning.

Summary

  • A personal design system has five parts: palette, type scale, spacing, components, README.
  • Keep each part small and practical.
  • Build the five components you actually use most.
  • Write a one-page README so future you follows the rules.
  • Apply it immediately to one real profile or document.
